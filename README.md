# AI Kitchen（PWA v1）

AI（愛）で、家族のごはんを。買い物・在庫・献立・調理をまとめて管理するスマホアプリ（PWA）。
※「AI」は人工知能と「愛」のダブルミーニング。

- ホワイト基調＋ハーブグリーン。Pixel のホーム画面にインストールできる。
- データは**端末内（localStorage）**に保存。オフラインでも起動する。
- 献立は **Google Gemini（Flash-Lite／Flash）** が在庫・常備品・家族構成から生成。
- **複数世帯**（林家 / 実家）を切り替え。世帯ごとにモード（標準／食べ盛り／シニア）、家族、在庫、買い物を別管理。
- 生年月日から**年齢を自動計算**（更新不要）。
- 「作った」で在庫を**手で調整**して減らせる（使い切った物は買い物へ自動追加）。

## 動かし方（ローカル）

Service Worker を使うため、ファイルを直接開くのではなく簡易サーバー経由で開きます。

```
cd "D:\00.Personal\02.家族\kitchen-app"
python -m http.server 5173
```

ブラウザで http://localhost:5173/ を開く。

Node がある場合は `npx serve -l 5173 .` でも可。

## AI献立を使う

1. 右上のブランド名タップ →「この世帯の設定・家族」→「APIキー」
2. **Google Gemini** の APIキー（`AIza...`、aistudio.google.com で無料発行）を入力して保存
3. モデルは **最安（Flash-Lite）** か 高品質（Flash） を選択
4. 「献立」タブ →「AIに献立を提案してもらう」

キー未設定でも**見本献立**で全画面が動作します。

> セキュリティ注記：v1 はキーを端末内に保存し、ブラウザから直接 Gemini を呼びます。**配布時は各自が自分の無料キーを入れる**運用（不特定多数に配れる）。**販売する場合は、キーをサーバー側に置く方式**（利用者はキー不要・こちらで課金）に切り替えます。同期を入れるタイミングで一緒に設計します。

モデルID：Flash-Lite=`gemini-2.5-flash-lite` / Flash=`gemini-2.5-flash`（`js/api.js` の `MODELS` で変更可）。

## スマホ（Pixel）へのインストール

PWA のインストールには HTTPS 配信が必要です（ローカルの `localhost` では自分の PC 内のみ）。実機に入れるには、静的ホスティング（例：Cloudflare Pages / GitHub Pages / Netlify など）に一式を置き、Chrome で開いて「ホーム画面に追加」します。ここは配信先を決めてから対応します。

## ファイル構成

```
index.html            画面の骨格（ステータスバー・タブバー等）
manifest.webmanifest  PWA 設定（インストール情報）
sw.js                 Service Worker（オフラインキャッシュ）
css/styles.css        デザイン一式
js/
  main.js   起動・SW登録
  ui.js     画面描画・シート・操作ハンドラ（本体）
  store.js  状態管理・端末内保存・世帯データ（← 将来ここを同期基盤に差し替え）
  api.js    Gemini 献立生成 + 見本献立
  util.js   日付・年齢・整形ヘルパー
  icons.js  手描きSVGアイコン
icons/      アプリアイコン
```
